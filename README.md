# @Animeshmitra08/react-native-ui-kit

A typed, themeable React Native UI component library.

## Installation

This package is published to **GitHub Packages**. GitHub Packages requires authentication even for public packages.

1. Create a GitHub [personal access token (classic)](https://github.com/settings/tokens) with the `read:packages` scope.

2. Expose the token as the `GITHUB_PACKAGES_TOKEN` environment variable:

   ```bash
   # macOS / Linux
   export GITHUB_PACKAGES_TOKEN=ghp_yourtoken
   ```

   ```powershell
   # Windows (persists for new terminals)
   setx GITHUB_PACKAGES_TOKEN ghp_yourtoken
   ```

3. In your app's project root, create or extend `.npmrc` (the scope must be lowercase):

   ```ini
   @Animeshmitra08:registry=https://npm.pkg.github.com
   //npm.pkg.github.com/:_authToken=${GITHUB_PACKAGES_TOKEN}
   ```

4. Install:

   ```bash
   npm install @Animeshmitra08/react-native-ui-kit
   ```

### Install directly from Git

Alternatively, install straight from the repository (no registry or token needed for a public repo). npm builds the package on install via the `prepare` script:

```bash
npm install github:Animeshmitra08/expo-ui
# or a specific tag / branch
npm install github:Animeshmitra08/expo-ui#v1.0.0
```

### Peer Dependencies

```bash
npm install react react-native
```

## Quick Start

Wrap your app with the `ThemeProvider`:

```tsx
import { ThemeProvider, Button, TextInput, Card } from '@Animeshmitra08/react-native-ui-kit';

export default function App() {
  return (
    <ThemeProvider>
      <Card elevated>
        <TextInput label="Email" placeholder="you@example.com" />
        <Button title="Sign In" variant="primary" />
      </Card>
    </ThemeProvider>
  );
}
```

## Components

| Component    | Description                                   |
| ------------ | --------------------------------------------- |
| `Button`     | Pressable button with variants, sizes, icons  |
| `TextInput`  | Styled text input with label, error, helpers  |
| `Card`       | Container with border / elevation             |
| `Avatar`     | Circular image or initials                    |
| `Badge`      | Small status label chip                       |
| `Divider`    | Horizontal or vertical separator              |
| `Switch`     | Animated toggle switch                        |
| `Checkbox`   | Checkable box with label                      |
| `Heading`    | Heading text (levels 1–4)                     |
| `Paragraph`  | Body text                                     |
| `Caption`    | Secondary small text                          |
| `Spinner`    | Loading indicator with optional message       |

## Theming

Built-in `lightTheme` and `darkTheme` are provided. You can also pass a custom `Theme` object:

```tsx
import { ThemeProvider, lightTheme } from '@Animeshmitra08/react-native-ui-kit';

const myTheme = {
  ...lightTheme,
  colors: { ...lightTheme.colors, primary: '#E11D48' },
};

<ThemeProvider initialTheme={myTheme}>
  {/* ... */}
</ThemeProvider>
```

Use the `useTheme()` hook inside any component to access the current theme:

```tsx
import { useTheme } from '@Animeshmitra08/react-native-ui-kit';

function MyComponent() {
  const { theme, isDark, toggleTheme } = useTheme();
  // ...
}
```

## Building

```bash
npm run build       # Builds CJS + ESM + type declarations
npm run dev         # Watch mode
npm run typecheck   # Run tsc --noEmit
```

`dist/` is not committed — it is generated by the `prepare` script on `npm install`, on Git installs, and before publishing.

## Publishing

Publishing is automated by [`.github/workflows/publish.yml`](.github/workflows/publish.yml):

1. Bump the version: `npm version patch` (or `minor` / `major`).
2. Push the commit and tag: `git push --follow-tags`.
3. Create a GitHub Release from the tag — the workflow builds and publishes to GitHub Packages.

To publish manually instead, set `GITHUB_PACKAGES_TOKEN` to a token with the `write:packages` scope and run `npm publish`.
